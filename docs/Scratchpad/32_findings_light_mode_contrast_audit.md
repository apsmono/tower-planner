# Findings on Light Mode Button States

## Research Queue Tab
* **Active Toggle Button ("SPLIT (SCORE / DAY)")**: Has a dark indigo background (`bg-indigo-600`) but the text is rendered in a dark blue/black color. This creates a severe contrast issue, making the text highly unreadable.
* **Inactive Toggle Button ("UNIFIED (SCORE / COIN)")**: Has a light background with slate text. Readable and clear.
* **Active Category Pill ("All Labs")**: Has a dark indigo background with dark text. Hard to read.
* **Inactive Category Pills**: Have a light gray background with dark text. Good readability.

## Build State Tab
* **UWs -> "All (9)" Active Button**: Indigo-600 background but dark text. Hard to read.
* **UWs -> Inactive Buttons**: Soft slate background with dark text. Readable.
* **Goals -> "Research" Active Button**: Indigo-600 background but dark text. Hard to read.
* **Goals -> "Resource" Inactive Button**: Soft slate background with dark text. Readable.
